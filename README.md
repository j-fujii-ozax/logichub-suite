# 📦 LogicHub Suite
### 需要予測を「実運用可能な計画」へ変換する SCM 最適化ツールキット

LogicHub は、AIや基幹システムから出力された需要予測データを、物流・製造現場の制約（MOQ、生産キャパシティ、リードタイム等）に合わせて自動調整・加工するためのブラウザ完結型ツール群です。

## 🚀 主な機能

- **🏭 Production Scheduler (v1.5)**
  - 発注/需要予測から着工予定日を逆算。
  - ライン別の生産キャパシティに基づき、商品を自動割り当て・平準化。
- **📦 Smart Order Optimizer (v2.4)**
  - サプライヤーごとのMOQ（最低発注量）や結束単位を自動適用。
  - 不足分の自動補正と、ブラウザ上での微調整機能。
- **📊 Time-Bucket Aggregator (v2.10)**
  - 日次データを週次・月次のカレンダー形式へ変換。
  - サプライヤー・拠点・商品別の需要波動を可視化。
- **🔄 Column Shuffler (v1.4)**
  - CSVのカラム名変更・並び替え・削除をブラウザで完結。
  - システム間連携のフォーマット変換を自動化。

## 🛠 テクノロジー
- **PyScript**: ブラウザ上で Python (Pandas/Numpy) を直接実行。
- **HTML5 / CSS3**: モダンなレスポンシブUI。
- **Client-Side Processing**: データのアップロードやサーバー送信は一切行いません。すべての処理は利用者のブラウザ内で行われるため、機密データの扱いも安全です。

## 📖 使い方
1. GitHub Pages で公開されたURLにアクセスします。
2. ポータル画面（index.html）から、目的に合ったツールを選択します。
3. 需要予測結果（CSV形式）をアップロードします。
4. パラメータを設定し「実行」ボタンを押します。
5. プレビューを確認し、必要に応じて結果をCSVとしてダウンロードします。

## 📂 ファイル構成
- `index.html`: 統合ポータル画面
- `production_scheduler.html`: 生産計画レコメンダー
- `order_logic.html`: 発注最適化ツール
- `time_bucket.html`: 期間集計カレンダー
- `column_shuffler.html`: データ整形ユーティリティ
